# 🏗 Indian Scrap Management Web App

This is a full-stack web application built for managing scrap pickup requests across India. It includes user authentication, pickup scheduling, and SMS/email notifications.

---

## 📦 Features

✅ User Registration & Login  
✅ Admin Dashboard to View Pickups  
✅ Pickup Request System  
✅ SMS Notification (Twilio)  
✅ Email Alerts (Gmail SMTP)  
✅ MongoDB Atlas Integration  
✅ Deployed on DigitalOcean App Platform

---

## 🧩 Tech Stack

- **Frontend:** React (with React Router)
- **Backend:** Node.js + Express
- **Database:** MongoDB Atlas
- **Notifications:** Twilio SMS + Gmail SMTP
- **Deployment:** GitHub + DigitalOcean App Platform
